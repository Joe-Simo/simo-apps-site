Support is by email only. We aim to reply within 2 business days. Please include your Freshdesk domain, the ticket number and a screenshot of the message you see. Never send your API key.

Frequently asked questions

Who can approve?

Only the agents picked on the request (1 to 5), and only while they are active agents in your helpdesk. The agent who asked can never approve or reject their own request.

What is the difference between "any one" and "all"?

With "any one", the first approval approves the request, and it is rejected only when every approver has rejected it. With "all", every approver must approve, and one rejection rejects it.

How are approvers told about a request?

The app adds a private note to the ticket and lists the approvers in the note's notify list, so Freshdesk sends them its normal email. You can turn this off under Settings. The note is added either way.

Can the ticket status change automatically?

Yes, if you choose statuses under Settings: one while the request waits, one when it is approved and one when it is rejected. Leave a field empty to keep the status as it is.

How do automatic rules work?

When a ticket is created or updated and matches a rule (type, group, priority, tag or a number field threshold), the app opens a request with the rule's approvers. Every condition you fill in must match. Each rule opens a request on a ticket only once. You can have up to 10 rules. A request opened by a rule can be cancelled by one of its approvers.

Can a request be cancelled?

Yes. The agent who asked can cancel an open request from the sidebar. The cancel is recorded in a private note.

What is in the CSV export?

The decision log: time (UTC), ticket, request, event, agent, rule, amount and comment for roughly the last 1,000 events. Cells that start with =, +, - or @ are escaped so spreadsheets do not run them as formulas.

Limits

1 to 5 approvers per request, reasons up to 500 characters, comments up to 300 characters, up to 1,000 open requests at once and the newest 5 requests kept per ticket.

The sidebar shows an error.

Reload the ticket. If it continues, check that the API key in the app settings belongs to an active admin agent, and email us with a screenshot.
