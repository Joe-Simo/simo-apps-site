Step by step checklists on Freshdesk tickets

Ticket Checklists keeps the steps of a process on the ticket: new hire onboarding, refund approval, hardware returns, escalations. Checklists are added automatically to the right tickets, agents tick items as they work, and required steps must be done before the ticket is resolved or closed. Freshdesk has no built-in ticket checklist.

The process, on every ticket

  • Build checklists once

    Up to 50 checklists with up to 50 items each, on one admin page. Start a line with * to make an item required.

  • Added automatically

    Add a checklist to every new ticket, or to tickets of chosen types, groups, priorities or tags, when they are created or updated.

  • Who and when

    In the ticket sidebar agents tick items as they go. Each item shows who completed it and when, with a progress bar per checklist.

  • Required before Close

    Turn on blocking and the ticket page will not resolve or close the ticket while required items are open. The agent sees what is missing.

  • Private note on completion

    When a checklist is complete, the app can add a private note listing every item and who did it, so the record stays in Freshdesk.

  • Add or remove by hand

    Agents can add any other checklist to a ticket or remove one that does not apply. A removed checklist is not added back by its rule.

How it works

  1. Install Ticket Checklists from the Freshworks Marketplace and enter your Freshdesk domain and an admin API key.
  2. Open Ticket Checklists from the apps menu, click New checklist, enter the items and choose which tickets get it.
  3. Open a matching ticket: the checklist is in the Ticket Checklists sidebar.

Blocking applies to the Close button and status changes on the ticket page. The ticket list view, bulk actions, automations and the API are not blocked.

Private by design

Ticket Checklists runs entirely on the Freshworks platform. Your API key is stored as an encrypted installation parameter and is used only to call your own Freshdesk account. No data leaves Freshworks. Read the full privacy policy.
