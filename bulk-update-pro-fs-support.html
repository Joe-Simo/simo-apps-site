Bulk Update Pro for Freshservice support

Contact

Email: joesimo@mail.grokbot.com

Support is by email only. We aim to reply within 2 business days. Please include your Freshservice domain, the job number (for example j12) and a screenshot of the message you see. Never send your API key.

Frequently asked questions

A name in my changes is "unknown" or "matches more than one".

Bulk Update Pro uses the labels from your Freshservice ticket form, your group, agent and department names, and agent emails. If two agents share a name, use the agent's email. If two custom fields share a label, use the field's API name (for example cf_region).

How do I set a category?

Write the levels separated by ">", for example "Category: Hardware > Laptop > Mac". Levels you leave out are cleared.

How do I clear a field?

Write (empty) as the value, for example "Region: (empty)", "Agent: unassigned" or "Department: none".

How do private notes work?

Add a line such as "Private note: Closed during the October cleanup". The note is posted once on every ticket the job changes, or on every ticket when the note is the only line. Write the note on one line. Undo does not remove notes.

How fast does a job run?

About 8 tickets every 30 seconds while the app page is open, and 8 tickets every 5 minutes when it is closed. When few Freshservice API calls are left in the current minute, the job waits a minute so your agents and other apps keep working.

The job says it is waiting after a Freshservice limit or error.

It continues automatically. After a rate limit it waits the time Freshservice asks for. After an API key problem it waits 15 minutes; check that the API key in the app settings belongs to an active admin agent.

Some tickets show "Failed".

The log shows the reason Freshservice gave, for example a category that must be set before a ticket can be resolved or closed, or a ticket in a workspace the API key cannot access. Other tickets in the job are not affected.

Some tickets show "Left as is".

Someone changed the ticket while the job was running, so Bulk Update Pro did not overwrite their change.

Undo did not restore some fields.

Undo only restores a field if it still holds the value the job wrote. If your team changed it afterwards, their change is kept and the log lists the field as not restored. Undo can also fail on a ticket when your current form rules no longer allow the old values, for example a category that is now required before closing.

How many tickets can a job hold, and how many jobs are kept?

Up to 5,000 tickets per job, and one job runs at a time. The 9 most recent jobs and their change logs are kept; older ones are overwritten by new jobs. Download any log page you need as CSV.

Why does the log show numbers for groups, agents and departments?

The log stores the values Freshservice saves on the ticket, which are IDs for groups, agents and departments. The preview shows their names.

Can I change the ticket type?

No. Freshservice sets Incident or Service Request when the ticket is created.

Can I pick tickets by a filter instead of pasting numbers?

Not yet. Export the ticket numbers from a Freshservice ticket view and paste them.

What does it cost?

USD 19 per account per month, for any number of agents, billed through the Freshworks Marketplace.
