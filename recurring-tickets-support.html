Support is by email only. We aim to reply within 2 business days. Please include your Freshdesk domain, the template name and a screenshot of the message you see. Never send your API key.

Frequently asked questions

How close to the scheduled time is a ticket created?

The app checks every 5 minutes for templates that are due, so a ticket is normally created within 5 minutes after its time. If many templates are due at the same moment, up to 8 are handled per check and the rest follow on the next checks.

Which time zone is used?

Each template has its own time zone. A new template starts with your Freshdesk account time zone, and you can type any time zone name such as Europe/London. The template list shows times in the default time zone. To change the default, choose Change default time zone under the template list; existing templates keep their own time zone.

What happens on the 31st in a month with 30 days?

A monthly template on a day the month does not have runs on that month's last day. To always use the last day, choose "Last day".

What do {{date}} and the other placeholders produce?

{{date}} gives the date of the occurrence like 2026-11-16, {{weekday}} the day name, {{day}} the day number, {{month}} the month name, {{year}} the year and {{time}} the scheduled time like 09:00. They work in the subject and description.

Does Run now change the schedule?

No. Run now creates one ticket at once and the next scheduled ticket stays as shown.

I paused a template. Will the missed tickets be created when I resume?

No. Resuming continues with the next scheduled time. Nothing missed while paused is created.

A run shows "Failed".

The history shows the reason Freshdesk gave, for example a group or agent that no longer exists, or a custom field that needs a different value. Edit the template, fix the field and use Run now to test it.

A run shows "Not confirmed".

Freshdesk did not answer clearly twice, and the app could not find the ticket among the requester's recent tickets. It skipped that occurrence instead of risking a duplicate. Check the requester's tickets in Freshdesk.

The page says the API key was rejected.

Ticket creation is paused for 30 minutes after an API key error. Update the API key in the app settings with the key of an active admin agent.

Will the requester get an email?

Freshdesk treats the ticket like any new ticket, so your Freshdesk email notification settings decide whether the requester is notified. Many teams use an internal address as the requester for recurring tasks.

How many templates can I have?

Up to 100 per Freshdesk account.
