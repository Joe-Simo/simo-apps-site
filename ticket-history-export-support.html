Ticket History Export support

Contact

Email: joesimo@mail.grokbot.com

Support is by email only. We aim to reply within 2 business days. Please include your Freshdesk domain, the export number shown under "Recent exports" and a screenshot of the message you see. Never send your API key, and do not send an exported file unless we ask for it.

Frequently asked questions

Which format should I pick?

CSV per message gives one row per message with the ticket columns repeated, which is best for filtering and analysis in a spreadsheet. CSV per ticket gives one row per ticket with the whole conversation in one cell. The HTML transcript is one readable page with every ticket and message, which you can open in any browser and print or save as PDF.

What is included?

For each ticket: a link, subject, status, priority, type, group, agent, requester name and email, company, tags, created and updated dates and your custom fields. Then every message in time order: the description, public replies, private notes and forwarded emails, with sender, recipients, CC, date, text and attachment names.

Can I leave out private notes?

Yes. Untick "Include private notes" before you start the export. Do this before sending an export to a customer.

How many tickets can one export hold?

Up to 5,000 tickets per export, whether they come from filters or pasted IDs. For more, split the date range into several exports. One export runs at a time.

How fast does an export run?

Each batch uses up to 12 Freshdesk API requests. With the page open, a batch runs about every 30 seconds; with it closed, every 5 minutes. A ticket with a short conversation takes about two requests, so a page left open exports roughly 10 tickets a minute. This keeps well under the Freshdesk API rate limits so your other apps and integrations keep working.

Some tickets show as failed.

A ticket that was deleted, or an ID that does not exist, is counted as failed and the export moves on.

Why are attachments not in the file?

The export lists attachment names with each message. The files stay in Freshdesk, where you can open them from the ticket link.

Are archived tickets included?

No. Freshdesk does not return archived tickets through the regular ticket API.

A message ends with a note that it was cut.

Bodies longer than 20,000 characters are cut so very long email threads still fit. The full message stays in Freshdesk.

How long can I download an export?

For 7 days after it finishes. After that it leaves the export list, the stored copy expires automatically and you can start the export again.

Why does a large download take a few minutes?

Freshworks app storage allows about 50 reads a minute per installation, so a large export is read page by page. Keep the app page open until the file is saved. If storage is busy the app waits and tries again on its own.

The download says the link is no longer valid.

Click Download again to start over from the first page.

Why does the CSV put a ' in front of some cells?

Cells that start with =, +, - or @ get a leading ' so a spreadsheet program does not run them as formulas.

Why does the app ask for my API key when I open it?

Exports can contain every ticket and private note, so only Freshdesk admins can use the app. Paste your own key from Profile settings, View API key. The app asks Freshdesk who owns the key and whether you have the Account Administrator or Administrator role. The key is used for that one check and is not stored. The session ends after 30 minutes or when you select Sign out.

It says only Freshdesk admins can use the app.

Your Freshdesk role is not Account Administrator or Administrator. Ask an admin to run the export, or to give you one of those roles.

Why does Cancel export ask me to confirm?

A cancelled export cannot be resumed, so the app asks once more. Select Confirm to cancel or Back to keep it running.

Does the app change my tickets?

No. It only reads tickets and conversations.
