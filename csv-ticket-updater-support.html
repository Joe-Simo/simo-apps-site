CSV Ticket Updater support

Contact

Email: joesimo@mail.grokbot.com

Support is by email only. We aim to reply within 2 business days. Please include your Freshdesk domain, the job number (for example j12), the CSV row number and a screenshot of the message you see. Never send your API key, and do not send the whole CSV unless we ask for it.

Frequently asked questions

What should my CSV look like?

The first row is the header. The first column, or a column named Ticket ID, holds the ticket number. Every other column is a ticket field named as in Freshdesk, for example Status, Priority, Group, Agent or a custom field label. Click "Download sample CSV" in the app to get a header built from your own fields.

A column is "unknown".

CSV Ticket Updater uses the labels from your Freshdesk ticket form. Check the spelling in the header row. Upper and lower case do not matter. The supported default columns are Status, Priority, Type, Group, Agent, Add tags and Remove tags.

Some rows are listed under "Rows with problems".

Each problem shows the CSV row number and the reason, for example a dropdown value that is not one of the choices, an agent email that does not match an agent, or a ticket number that is not a number. Fix those rows and preview again, or tick "Skip these rows" to update only the rows without problems.

How do I leave a field alone, and how do I clear it?

An empty cell leaves that field as it is. Write (empty) in a cell to clear the field on that ticket.

How large can a file be?

Up to 5,000 rows and 2 MB per file. Split larger files into several jobs. One job runs at a time.

How fast does a job run?

About 8 tickets every 30 seconds while the app page is open, and 8 tickets every 5 minutes when it is closed. This keeps well under the Freshdesk API rate limits so your other apps and integrations keep working.

The job says it is waiting after a Freshdesk limit or error.

The job continues automatically. After a rate limit it waits the time Freshdesk asks for. After an API key problem it waits 15 minutes; check that the API key in the app settings belongs to an active admin agent.

Some tickets show "Failed" or "Not found".

The log shows the reason Freshdesk gave, for example a required field that must be filled before a ticket can be closed, or a ticket that was deleted. Other rows in the job are not affected.

Some tickets show "Left as is".

Someone changed the ticket while the job was running, so CSV Ticket Updater did not overwrite their change.

Undo did not restore some fields.

Undo only restores a field if it still holds the value the job wrote. If your team changed it afterwards, their change is kept and the log lists the field as not restored.

Why does the results CSV put a ' in front of some cells?

Cells that start with =, +, - or @ get a leading ' so a spreadsheet program does not run them as formulas.

How is this different from Bulk Update Pro?

Bulk Update Pro applies the same change to a list of tickets. CSV Ticket Updater applies a different change to each ticket from a spreadsheet. They work well side by side.
