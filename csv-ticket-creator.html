Create Freshdesk tickets from a spreadsheet, one per row

Freshdesk imports contacts and companies from a CSV, but not tickets. CSV Ticket Creator turns every row of your file into its own ticket, or sends one personalized email per row from your support address. Up to 5,000 rows per file, with a preview that checks every row first.

Bulk ticket creation you can check first

  • One row, one ticket

    Each row needs a subject and a requester: an email, or a phone number plus a name. Add Description, Tags, CC, Company, Due by, Private note or any ticket field by its Freshdesk label.

  • Defaults for every ticket

    Set Status, Priority, Type, Group, Agent and Tags once for rows that leave them empty. Write values the way you read them: "Billing", "High", an agent's name or email.

  • An email per row

    Write the subject and message once with {{Column}} fields, pick a support address, and every row gets its own outbound email and ticket. You type the number of emails before the job starts.

  • Every row checked first

    The preview lists rows with problems by CSV row number and reason and shows the first tickets exactly as they will be created. Skip bad rows on purpose, never by accident.

  • No duplicate tickets

    Jobs run in small background batches and resume after a rate limit or outage. A row whose result is uncertain is marked for you to check, never sent twice. Every ticket gets a job tag.

  • Results CSV and undo

    Download the results with a link to every new ticket. Undo moves a create job's tickets to Trash, but keeps any ticket your team already replied to.

How it works

  1. Install CSV Ticket Creator from the Freshworks Marketplace and enter your Freshdesk domain and an admin API key.
  2. Choose Create tickets or Send an email per row, then download the sample CSV or use your own sheet.
  3. Upload or paste the CSV, set any defaults, click Preview and fix or skip any rows with problems.
  4. Click Start job. Follow progress, filter Freshdesk by the job tag, download the results CSV or undo.

Private by design

CSV Ticket Creator runs entirely on the Freshworks platform. Your API key is stored as an encrypted installation parameter and is used only to call your own Freshdesk account. No data leaves Freshworks. Read the full privacy policy.
