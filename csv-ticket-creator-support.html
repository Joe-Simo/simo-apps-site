CSV Ticket Creator support

Contact

Email: joesimo@mail.grokbot.com

Support is by email only. We aim to reply within 2 business days. Please include your Freshdesk domain, the job number (for example j12), the CSV row number and a screenshot of the message you see. Never send your API key, and do not send the whole CSV unless we ask for it.

Frequently asked questions

What should my CSV look like?

The first row is the header. Each row needs a Subject and a requester: a Requester email column, or a Phone column together with a Requester name column. Optional columns: Description, Tags, CC, Company, Due by, Private note, External ref and any ticket field named as in your Freshdesk ticket form, for example Type, Group, Agent or a custom dropdown. Upper and lower case do not matter.

Some rows are listed under "Rows with problems".

Each problem shows the CSV row number and the reason, for example an empty subject, an invalid email, a company name that does not exist, a dropdown value that is not one of the choices or a required field left empty. Fix those rows and preview again, or tick the option to skip them and create only the rows without problems.

What happens to empty cells?

An empty cell uses the value from the defaults panel. Without a default, Status is Open and Priority is Low, and other fields stay empty.

How do I send a personalized email to every row?

Pick "Send an email per row", choose the support address to send from, and write the subject and message with {{Column}} fields, for example {{First name}}. Every row needs a requester email. The preview shows how the first emails will read and lists any column a template uses that the file does not have. Before the job starts you type the number of emails to confirm. Use this mode only for people who expect to hear from you.

How large can a file be?

Up to 5,000 rows and 2 MB per file. Split larger files into several jobs. One job runs at a time.

How fast does a job run?

Up to 12 tickets every 30 seconds while the app page is open, and up to 12 every 5 minutes when it is closed. Rows with a private note take two requests, so those jobs run slower. This keeps well under the Freshdesk API rate limits so your other apps and integrations keep working.

A row says "unknown".

The connection to Freshdesk dropped while that ticket was being created, so the app cannot tell whether Freshdesk created it. To avoid a duplicate ticket the app does not send that row again. Filter your tickets by the job tag (for example csv-import-20261114-1) to check, and add the row to a new file only if the ticket is missing.

Can I import my old ticket dates?

No. Freshdesk gives every new ticket the date it was created. Put the original date in a custom field or the description if you need it.

What does Undo do?

Undo moves the tickets a create job made to Trash, where you can restore them in Freshdesk. A ticket that already has a reply or note from someone else is kept and listed as kept. Email per row jobs cannot be undone, because the emails are already sent.

Why does the results CSV put a ' in front of some cells?

Cells that start with =, +, - or @ get a leading ' so a spreadsheet program does not run them as formulas.

How is this different from CSV Ticket Updater?

CSV Ticket Creator makes new tickets. CSV Ticket Updater changes existing tickets, with a different value per ticket. They work well side by side.
