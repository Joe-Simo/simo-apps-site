Frequently asked questions

Which tickets does the app assign?

New service tickets in a group you manage that have no agent yet and are not spam. When you turn on the option, it also assigns a ticket that is moved into a managed group without an agent. It never replaces an agent who is already set.

How does Fewest open pick the agent?

It gives the ticket to the available agent with the fewest open and pending tickets. Ties go to the agent with the fewest tickets from the app today, then to your order. Open counts come from Freshservice at each catch-up check, every 5 minutes, and tickets the app assigns in between count right away.

What are the other modes?

Round robin gives each new ticket to the next agent in your order. Fewest today gives it to the available agent with the fewest tickets from the app today, and ties go by order. Today's counts reset at midnight in the time zone you choose for the group.

When is an agent skipped?

When they are out of queue, outside their shift hours, or at their cap of open and pending tickets. An agent with no shift hours is always on shift, and an empty cap means no cap.

Does the app use the Freshservice availability toggle or work schedules?

No. The app uses its own queue switch and shift hours, which you set on the admin page. Under Queue today, select Take out or Put in queue for any agent.

Should I turn off automatic assignment in Freshservice?

Yes, for the groups this app manages. Go to Admin, Groups, open the group and turn off automatic ticket assignment. The app checks the live setting on every run and skips a group if automatic assignment is on or the setting cannot be read. The admin page shows a warning when it is on.

Does it replace Assignment Policies or skills routing?

No. The app balances new tickets inside a group by open ticket load, with caps and shifts. It does not route by skills, by ticket fields or by agent load weights, and it does not move tickets between groups.

What happens to tickets when nobody is available?

They stay unassigned. A catch-up check every 5 minutes assigns waiting tickets, oldest first, as soon as an agent is free. Before it assigns a ticket it reads it again, so a ticket someone assigned by hand in the meantime is left alone.

How many tickets can it assign?

About 8 assignments per minute per account, which is set by the Freshworks app storage limits. Tickets above that stay unassigned for a few minutes and are picked up by the catch-up check, up to 5 per check.

Does it use my Freshservice API limit?

A little. Each assignment takes a few calls, and the catch-up check counts open tickets for the agents in each rotation. Freshservice limits are account wide (100 calls per minute on Starter), so on Starter with large rotations, use caps only where you need them or keep rotations small.

What if a ticket turns out to be spam or is deleted?

If a ticket the app assigned is marked as spam or deleted within a day, the agent gets the turn back and today's count goes down. Merged tickets are not detected and still count.

Can I see who got which ticket and why?

Yes. The admin page shows who is next in each group, open counts, today's counts and the recent assignments with the reason for each, and you can download the last 200 as a CSV file. You can also turn on a private note on each assigned ticket that names the agent and the reason.

Does it work with several workspaces?

It manages agent groups of the primary workspace.

Why does the app ask for my API key?

Everyone signs in once per session with their own Freshservice API key (Profile settings, Your API key). Freshservice confirms who you are, so only admins can see and change the settings. The key is used for that one check and is not stored, and the session ends after 30 minutes.

Who can change the settings?

Only Freshservice admins (Account Admin, Admin or another role of the admin type). Role changes apply at the next sign-in.

How do I stop the app for a while?

On the admin page, tick "Pause all assignment for now" and save. New tickets stay unassigned until you turn it off. Uninstalling the app removes its catch-up check.

Tickets are not being assigned.

Check that the group is ticked under Groups, that its rotation has agents who are in queue, on shift and under their cap, and that assignment is not paused. Then check that the API key in the app settings belongs to an active admin agent, and email us with a ticket number if it continues.
