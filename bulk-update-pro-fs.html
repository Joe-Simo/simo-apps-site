Update thousands of Freshservice tickets, with a preview and an undo

Bulk Update Pro changes fields on up to 5,000 Freshservice tickets per job. Write changes the way you see them in Freshservice, review a preview before anything changes, add the same private note to every ticket, let the job run in the background, and undo it if you need to.

Bulk changes you can trust

  • Changes by field name

    Write "Status: Pending", "Urgency: High", "Department: Finance" or "Category: Hardware > Laptop > Mac". Names are matched to your own fields, groups, agents and departments, and anything unknown or ambiguous is reported instead of guessed.

  • Preview first

    See exactly what will change on the first tickets, with your own field labels. A job can only start from the preview you reviewed.

  • Private notes and presets

    Add one "Private note:" line to post the same note on every ticket the job changes, never twice on the same ticket. Save change sets you use often as presets.

  • Runs in the background

    Small batches leave API calls free for your agents and other apps, keep going with the page closed, and resume where they stopped after a rate limit or outage.

  • Undo that respects your team

    Previous values are logged before each update. Undo restores only fields that still hold the value the job wrote, so later edits are never overwritten.

  • Change log and CSV

    Every ticket's result and previous values are kept in a log you can browse in the app and download page by page as CSV. Pause, resume or cancel any job.

How it works

  1. Install Bulk Update Pro for Freshservice from the Freshworks Marketplace and enter your Freshservice domain and an admin API key.
  2. Paste ticket numbers (INC-123, SR-45 or 123) or ticket links and write one change per line.
  3. Click Preview changes and review the result.
  4. Click Start job. Open View log at any time to follow progress, download the CSV or undo.

Good to know

  • Tickets are chosen by number or link. There is no filter or view selection yet; export the numbers from a ticket view and paste them.
  • Ticket type (Incident or Service Request) cannot be changed. Freshservice sets it when the ticket is created.
  • About 8 tickets every 30 seconds with the app page open, and 8 every 5 minutes when it is closed.
  • Undo restores fields and tags. Private notes stay on the tickets.

Private by design

Bulk Update Pro runs entirely on the Freshworks platform. Your API key is stored as an encrypted installation parameter and is used only to call your own Freshservice account. No data leaves Freshworks. Read the full privacy policy.
