Contact

Support is by email only. We aim to reply within 2 business days. Please include your Freshdesk domain, the checklist name, the ticket number and a screenshot of the message you see. Never send your API key.

Frequently asked questions

How do I make an item required?

On the admin page, start the line with *. For example "* Grant VPN access". Required items are marked in the ticket sidebar.

What does "Block Resolve and Close" do?

When it is on for a checklist and a required item is still open, the Close button and a status change to Resolved or Closed on the ticket page are stopped, and the agent sees which item is missing. It does not block the ticket list view, bulk actions, automations, the API or other apps.

When is a checklist added automatically?

When a ticket is created or updated and it matches the checklist's rule: every new ticket, or by type, group, priority or tag. Every condition you fill in must match, and a ticket matches a condition when it has any of the chosen values. A checklist is added to a ticket only once. Tickets that existed before you installed the app get matching checklists when an agent opens them.

An agent removed a checklist. Will it come back?

No. A checklist an agent removed is not added again by its rule on that ticket. An agent can still add it again by hand with Add checklist.

I changed a checklist on the admin page. Do tickets change too?

No. A ticket keeps the items it had when the checklist was added, so ticked items and their history stay correct. New tickets get the new version.

What is in the private note?

When every item of a checklist is ticked, the app adds one private note with the checklist name, every item and who ticked it. Turn this off with the setting under the checklist list.

How many checklists and items can I have?

Up to 50 checklists with up to 50 items each, 160 characters per item. A ticket can hold up to 6 checklists and 120 items.

The sidebar shows an error.

Reload the ticket. If it continues, check that the API key in the app settings belongs to an active admin agent, and email us with a screenshot.
