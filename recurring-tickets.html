Create the same Freshdesk ticket on a schedule

Recurring Tickets adds an admin page to Freshdesk where you build a ticket once as a template and choose when it repeats: a daily server room check, a weekly SLA report, a monthly access review. Freshdesk has no built-in way to repeat a ticket.

Get help Read the privacy policy

Repeating work, created on time

  • Flexible schedules

    Every day, every weekday, chosen days of the week, a day of the month, the last day of the month, or every 1 to 365 days. Each template has its own time, start date, optional end date and time zone.

  • See the next dates

    Before you save, the form lists the next 5 dates the ticket will be created. Times stay correct across daylight saving changes.

  • Any ticket fields

    Subject, description, requester, CC, group, agent, priority, status, type, tags and your custom fields, with dropdowns loaded from your own helpdesk.

  • Date placeholders

    Put {{date}}, {{weekday}}, {{month}} or {{year}} in the subject or description, for example "SLA report review: week of 2026-11-16".

  • Run now, pause, history

    Create one ticket at once without changing the schedule, pause and resume any template, and see every ticket it created with the reason for any failure.

  • No duplicates

    If Freshdesk does not answer clearly, the app looks for the ticket before trying again, so the same occurrence is not created twice.

How it works

  1. Install Recurring Tickets from the Freshworks Marketplace and enter your Freshdesk domain and an admin API key.
  2. Open Recurring Tickets from the apps menu and click New template.
  3. Choose the schedule, fill in the ticket fields and click Save template. The app checks every 5 minutes for templates that are due.

Private by design

Recurring Tickets runs entirely on the Freshworks platform. Your API key is stored as an encrypted installation parameter and is used only to call your own Freshdesk account. No data leaves Freshworks. Read the full privacy policy.
